# ALUGOLD ENTERPRISE Website

## Overview
A modern, responsive, high-performance website for ALUGOLD ENTERPRISE, a construction and consultation company specializing in aluminum solutions.

## Features
- Clean, professional design with gold and black color scheme
- Responsive layout for mobile, tablet, and desktop
- Service showcase with card-based layout
- Online booking system for services
- Shop page for construction materials
- Contact forms and CTAs

## Pages
- **Home (index.html)**: Hero section, introduction, services overview, about, contact
- **Booking (booking.html)**: Service booking with form
- **Shop (shop.html)**: Material sales

## Technologies
- HTML5
- Tailwind CSS
- Vanilla JavaScript

## Getting Started
1. Open `index.html` in a web browser
2. Navigate through the pages using the navbar

## Development
- Edit HTML files for structure
- Modify `styles.css` for custom styles
- Update `script.js` for interactivity

## Brand Colors
- Primary: Gold (#D4AF37)
- Secondary: Black (#0F0F0F)
- Neutral: White (#FFFFFF)
